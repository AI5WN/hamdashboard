PACU cam test bench

Each tile below is a real iframe embed, exactly like a dashboard tile, served from this same host so the browser sends a proper referrer. Whatever plays here will play on the dashboard; whatever shows an error here is genuinely unusable and needs replacing. Do not judge a stream by pasting an /embed/ URL into the address bar — that sends no referrer and fails with "Error 153" even for streams that embed fine. The green-bordered control is a cam already working on the board: if it plays and others do not, the others are the problem, not the network.
